# 阶段 10：求职备战（学习资料）

> 对应任务：MUJI-13（任务 10.1 ~ 10.5）｜ 持续进行

## 一、学习目标
- 简历呈现 1-2 个完整可演示的 Agent 项目
- 高频面试题 50 题以上脱稿作答
- 完成 ≥3 次模拟面试，进入真实面试流程

## 二、核心知识
1. **简历要点**：项目写"场景→方案→量化结果"（准确率提升 X%、成本降低 Y%）；附在线演示链接；GitHub 链接保持整洁（README 是第一印象）
2. **面试高频模块**（按权重）：
   - Agent 基础：什么是 Agent？与 LLM 应用的区别？四大组件？四大工作流模式？
   - 架构设计：ReAct 原理？如何设计智能客服 Agent？多 Agent 如何协作？如何保证可控安全？
   - 技术实现：LangChain vs LangGraph？如何优化性能/成本？如何调试？RAG 与 Agent 如何结合？
   - 项目深挖：技术难点？如何评估效果？上线后遇到什么问题？
3. **2026 面试热点**：MCP 协议、Agentic RAG、多 Agent 编排、安全与评测（LLM 评测体系）

## 四、行动清单
1. 项目复盘：梳理每个项目的难点、决策、量化结果（写文档）
2. 准备演示：录 3-5 分钟演示视频 + 一句话项目介绍
3. 刷题：每周 3-4 天，录音自测脱稿能力
4. 模拟面试：每周 1 次，复盘改进
5. 投递：每周 ≥5 家，记录面经，迭代简历

## 五、避坑
1. 别背答案：面试官追问三层的项目细节，背不出来更糟——项目必须是自己做的
2. 简历别堆砌关键词：每个技能点要能举出实际用例
3. 保持学习：AI 领域变化快，面经和新技术要持续跟进（读论文、跟社区）

## 六、验收标准
- [ ] 简历完成（含 1-2 个可在线演示项目）
- [ ] 50 题脱稿 + 3 次模拟面试
- [ ] 进入真实面试流程
