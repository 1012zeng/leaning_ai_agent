# 阶段 8：项目实战（学习资料）

> 对应任务：MUJI-11（任务 8.1 ~ 8.5）｜ 时长：约 4-7 周

## 一、学习目标
- 综合运用 1-7 阶段全部技能，完成 1-2 个完整、可展示、可写进简历的项目
- 学会项目规划：需求→设计→开发→评估→上线→复盘 全流程

## 二、项目方向参考
1. **智能客服 Agent**：多轮对话 + 订单查询（NL2SQL）+ RAG 知识库
2. **代码助手 Agent**：生成/解释/修复代码，接代码库检索
3. **数据分析 Agent**：自然语言→SQL→图表→报告（电商问数场景很吃香）
4. **内容创作 Agent**：搜索资料→生成文章→优化（多 Agent 流水线）
5. **个人助理 Agent**：日程管理 + 邮件 + 提醒（工具调用密集）

**建议**：选你自己工作/生活场景最贴近的——真实需求才能做出深度。参考 ai-agents-from-zero 的实战项目（NL2SQL+LangGraph 电商问数、DeepAgents 多智能体深度研搜）。

## 三、项目必须包含（缺一不可）
- 用户交互界面（Web UI，Streamlit/FastAPI+前端）
- ≥2 个工具集成（搜索/SQL/文件/API）
- 记忆系统（至少对话历史）
- 错误处理与重试
- 日志/观测（LangSmith）
- ≥20 条评估用例 + 成功率与成本数据

## 四、开发流程建议
1. 写需求文档（场景/用户/功能/技术选型/界面草图）→ 评审
2. 搭最小可用版本（核心流程先通）→ 再扩展
3. 评估集建立后锁定：每次改动跑回归
4. 部署上线 + README + 技术博客（输出倒逼输入）
5. 复盘：哪些设计失败？哪些指标未达？写进总结

## 六、避坑
1. 不要贪大：一个场景做深做透，胜过五个半成品
2. UI 是门面：丑但能用 > 炫但难用；先功能后美化
3. 数据先行：评估指标从第一天就开始记录
4. 文档即作品：README 写清"做了什么、怎么跑、效果如何"，面试官先看这个

## 七、验收标准
- [ ] 完整项目在线可访问 + 技术博客/演示视频 + 评估报告
- [ ] 建议做第二个不同方向的项目巩固
