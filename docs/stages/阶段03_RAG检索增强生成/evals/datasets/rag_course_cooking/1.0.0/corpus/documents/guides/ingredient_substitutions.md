# 常见食材替换指南

<!-- chunk: substitutions-eggs -->
## 鸡蛋替换

制作番茄汤时，每 1 个鸡蛋可用 50 克嫩豆腐作为口感替代；替换后不会形成蛋花，且不能再称为“番茄蛋汤”。

<!-- chunk: substitutions-dairy -->
## 乳制品替换

需要奶香时，牛奶可按 1:1 体积换成无糖椰奶。小米南瓜粥基础配方本身不含乳制品，无需为“无乳”额外替换。

<!-- chunk: substitutions-limits -->
## 使用边界

食材替换不能替代过敏原标签核对。共享厨房存在交叉接触时，不得仅凭“配方不含某原料”承诺零痕量。
