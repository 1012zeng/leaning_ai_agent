# 番茄蛋汤

<!-- chunk: tomato-soup-ingredients -->
## 原料（2人份）

- 番茄 300 克
- 鸡蛋 2 个
- 清水 600 毫升
- 盐 3 克
- 香油 2 毫升

<!-- chunk: tomato-soup-steps -->
## 步骤

番茄切块后中火炒 2 分钟，加入 600 毫升清水煮沸。把蛋液沿锅边细流倒入，等待 20 秒再轻推。蛋花成形后继续加热 90 秒，关火后加盐和香油。

<!-- chunk: tomato-soup-tips -->
## 关键提示

蛋液入锅后立即大幅搅动会让汤变浑。盐应在蛋花成形后加入；本文没有给出无蛋版本。
