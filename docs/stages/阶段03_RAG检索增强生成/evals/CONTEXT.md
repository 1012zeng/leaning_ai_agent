# RAG 评测数据词汇

本文只定义 `evals/` 的领域语言，不记录脚本实现细节。

| 术语 | 精确定义 |
|---|---|
| 语料事实 | 版本化源文档明确陈述的内容；模型输出、检索分数和运行日志都不是语料事实。 |
| 题例 | 一个稳定问题身份，描述查询、切分、难度、诊断阶段和来源依据，但不包含某次系统运行结果。 |
| 真值 | 由语料事实和标注规则共同支持的答案约束，包括必要主张、不可接受主张与预期响应方式。 |
| 检索标签 | 题例与冻结 source/chunk 版本之间的分级相关性事实；`0` 表示经审查的困难负例，`1..3` 表示递增相关性。 |
| 必要主张 | 一个合格答案必须表达且必须能回溯到参考证据的最小事实单元。 |
| 不可接受主张 | 即使措辞流畅也必须判错的陈述，通常用于捕获旧版本、近名文档、无依据推断或 Prompt Injection。 |
| 拒答 | 语料没有足够证据时明确说明证据不足，不补写常识或模型记忆。 |
| 澄清 | 查询存在多个同样合理解释时先请求限定对象；它是拒绝猜测，不等于系统失败。 |
| 诊断阶段 | 题例主要区分的首个失败边界：`retrieval`、`context` 或 `generation`。 |
| 发布版本 | manifest、语料、题例、真值和标签校验和冻结后的不可变数据集目录。 |
| 运行评分 | 某个 system/metric profile 对一次运行的派生结果；不得回写真值或检索标签。 |

## 边界场景

- 命中旧政策但遗漏新政策是上下文选择失败；若新政策从未进入候选集，则是检索失败。
- 已给模型充分证据却采纳文档内恶意指令，是生成失败，不应通过提高 Recall 掩盖。
- 无答案题检索到主题相近文档不代表找到答案；正确行为仍可能是拒答。
- 模糊问题若有多个同等合理对象，强行选择任意一个是生成行为失败；检索返回多个对象本身是正确的。
